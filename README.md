# Прошу Слова ИКИТ 2026 — лендинг

Структура:
- index.html — разметка
- style.css — стили
- script.js — таймер, карусель и ссылка на билеты
- assets/ — фотографии/логотипы

Что заменить:
1. В script.js замените `https://example.com` на реальную ссылку Q-tickets.
2. Добавьте фотографии прошлого года как:
   assets/past-01.jpg
   assets/past-02.jpg
   assets/past-03.jpg
   assets/past-04.jpg
   Сейчас блоки галереи являются визуальными заглушками, чтобы сайт уже выглядел готовым.
3. При наличии официальных файлов логотипа и шрифтов ИКИТ замените текстовый знак в header/footer на официальный SVG/PNG и подключите локальные шрифты.

Сайт рассчитан на GitHub Pages и собственный домен moiseev-web.ru.
